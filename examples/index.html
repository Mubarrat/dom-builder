Dom-Builder — Examples

Runnable demos for the Dom-Builder library.

Without Reaction (Dom-Builder only)

  • static Hello World — Build a card element declaratively.
  • static Static List — Render an array as a <ul> using .map().
  • static Contact Form — Declarative form with a submit handler.
  • static Data Table — Build a <table> from an array of objects.
  • static SVG Badges — Use $svg to compose SVG elements.

With Reaction (Dom-Builder + Observable)

  • reactive Live Counter — observable bound directly to the DOM.
  • reactive Todo List — arrayObservable, computed, and cstr.
  • reactive Live Search — Filter a list reactively as you type.
  • reactive Registration Form — .validatable(), computed error messages, and disabled submit.
  • reactive Optimistic Like Button — .optimistic() update with automatic rollback on failure.
